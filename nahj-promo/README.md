# نهج للاستشارات والتدريب — إعلان 20 ثانية (Remotion)

إعلان رأسي لريلز/تيك توك/شورتس: 1080×1920، 30fps، 600 إطار (20.000 ث)، H.264 + AAC.

**الملف النهائي:** `out/nahj-promo-20s.mp4`

## التشغيل والتصدير

```bash
npm install
npm run studio          # معاينة وتعديل حي في Remotion Studio
npm run build           # الصوت ← التصيير ← ضبط الجهارة (يُنتج out/nahj-promo-20s.mp4)
```

أو خطوة بخطوة:

```bash
npm run audio           # يولّد music.wav و sfx.wav ويضبط مستوى التعليق الصوتي (Python 3 + numpy + ffmpeg)
npm run render          # remotion render … --codec=h264 --pixel-format=yuv420p --color-space=bt709
npm run master          # ضبط الجهارة على ‎-14 LUFS / -1.5 dBTP دون إعادة ترميز الفيديو
```

> في بيئة لا تسمح لـ Remotion بتنزيل المتصفح، مرّر متصفحًا مثبتًا:
> `REMOTION_BROWSER=/path/to/chrome-headless-shell npm run render`

## قرارات التصميم

- **العربية:** يتحرك النص كلمةً كلمة (لا حرفًا حرفًا) وبلا `letter-spacing`، فتبقى الحروف متصلة. الاتجاه `rtl`، وكل الكشف يسير من اليمين إلى اليسار.
- **الخط:** Cairo (رخصة SIL OFL) محفوظ محليًا ويُحمَّل عبر `@remotion/fonts`، الذي يؤجل التصيير حتى يكتمل تحميل كل الأوزان.
- **الهوامش الآمنة:** أعلى 250px، أسفل 420px، يمين 150px (عمود أزرار الريلز). تقع كل النصوص بين y≈340 وy≈1400.
- **الشعار:** الملف الرسمي (عنابي + ذهبي على خلفية شفافة) يظهر على لوحة بيضاء ليحتفظ بألوانه ونسبه الأصلية (1788×1098)، لأنه يختفي إن وُضع مباشرة على العنابي.
- **الرسم البياني:** يصعد من اليسار إلى اليمين (العُرف المعتاد للرسوم البيانية)، بلا أرقام ولا محاور ولا ادعاءات.
- **بلا لقطات مصوّرة:** المشاهد كلها Motion Graphics، فلا ادعاء بتصوير فريق نهج أو مقرّها.
