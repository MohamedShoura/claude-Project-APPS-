> **الحالة:** حزمة جاهزة للتنفيذ. **الفيديو لم يُنتج بعد.**

## 2) النص الصوتي (VO) — للتسجيل

> الأداء: صوت نسائي هادئ، واثق، دافئ. السرعة الطبيعية ~2.3 كلمة/ث. لا تسريع.
> `/` = وقفة قصيرة (0.2 ث) · `//` = وقفة أطول (0.5 ث)

```
[0:00.3] تفكرين في إبرة نضارة، / ومحتارة إذا كانت مناسبة لكِ؟ //
[0:04.2] اليوم نتكلم عن [اسم المنتج المؤكد]. //
[0:06.7] قبل اختيار أي إجراء، / نبدأ بتقييم بشرتك / ومراجعة تاريخك الصحي، /
[0:10.9] ونوضح لكِ الفوائد المتوقعة / والمخاطر / والبدائل. //
[0:17.0] مو كل إجراء يناسب الجميع، /
[0:20.3] والنتائج تختلف من شخص لآخر. //
[0:26.4] احجزي استشارتك، / وخلّينا نناقش الخيارات المناسبة لبشرتك.
[0:30.2] — نهاية الكلام —
```

**ملاحظة توقيت:** النص كما هو (≈ 50 كلمة) يستغرق تقريبًا 23–25 ثانية بنطق طبيعي، فيتسع داخل 35 ثانية مع وقفات ومساحة صامتة للكلمات المتتابعة والبطاقة الختامية. **لا حاجة لحذف أو تسريع.** إذا جاء التسجيل الفعلي أطول من 30.2 ث تُقلَّص الوقفة بين المشهدين 2 و3 أولًا.

**النطق:** «خلّينا» بتشديد اللام · «مو» بضم خفيف · اسم المنتج يُنطق كما تعتمده الشركة المصنعة (يُضاف تشكيل/كتابة صوتية بعد التأكيد).

## 5) خطة التنفيذ المقترحة (Pipeline)

1. **تسجيل الصوت أولًا**: معلّقة خليجية حقيقية (مفضّل) أو TTS عربي خليجي عالي الجودة، ملف WAV 48kHz.
2. **إطار مرجعي** (Shot 0) → اعتماده بصريًا (الوجه، الحجاب، الألوان).
3. **Image-to-Video** لكل لقطة من الإطار المرجعي، 9:16، 1080p.
4. **مزامنة الشفاه** (Lip-sync) على كل لقطة متحدثة باستخدام مقاطع الصوت المقصوصة حسب التوقيت أعلاه. إذا كانت المزامنة العربية ضعيفة في اللقطات القريبة: استبدال 3A/3B بلقطات متوسطة-قريبة.
5. **المونتاج** (CapCut / Premiere / DaVinci): النصوص، الشعار، الترجمة، الموسيقى، التلوين.
6. **مراجعة طبية + تنظيمية** ثم التصدير والنشر.

## 6) تعليمات المونتاج والهوية

### الألوان

|-----------|-------|
| خلفيات البطاقات واللوحات | عاجي دافئ `#F5F0E8` |

| نص الترجمة | أبيض `#FFFFFF` مع ظل ناعم 40% أسود |

### الخطوط
- العناوين: **IBM Plex Sans Arabic SemiBold** أو **Tajawal Bold**.
- الترجمة والتنويهات: **IBM Plex Sans Arabic Medium**.

### المساحة الآمنة لريلز (1080×1920)
- **أعلى 220px:** خالٍ (اسم الحساب وأزرار الواجهة) — عدا شارة الذكاء الاصطناعي الصغيرة بعده مباشرة.
- **أسفل 420px:** خالٍ (الوصف وأزرار الصوت).
- **يمين 140px:** خالٍ (أيقونات الإعجاب والتعليق والمشاركة).
- المنطقة النشطة للنصوص: x 60–940 · y 230–1500.

### مواصفات النصوص
| العنصر | الموضع | الحجم | السلوك |
|--------|-------|-------|--------|
| شارة «مشهد تمثيلي مولّد بالذكاء الاصطناعي» | أعلى يسار، y≈235 | 26px، أبيض 85% على كبسولة عاجية شفافة 35% | ثابتة 0:00–0:35 |
| عنوان «تفكرين في إبرة نضارة؟» | الثلث العلوي، y≈420 | 64px | ظهور تدريجي + انزلاق 20px لأعلى، 0.4 ث |
| الكلمات المتتابعة (3) | يسار الكادر، y≈700/800/900 | 52px، موف على شريط عاجي | كل كلمة تظهر بـ Fade 0.3 ث وتبقى حتى 0:26 |
| الترجمة | مركز أفقي، y≈1300–1480 | 44px، سطران كحد أقصى، ~32 حرفًا للسطر | مطابقة لملف `subtitles_ar.srt` |
| التنويه الطبي | فوق الترجمة، y≈1200 | 30px، أبيض 90% | 0:21–0:26 ثم على البطاقة الختامية |

### البطاقة الختامية (0:30.5–0:35)
- خلفية عاجية `#F5F0E8` مع انتقال Dissolve 0.5 ث من آخر لقطة.
- **[شعار العيادة]** في المنتصف، y≈620، عرض ≤ 420px.
- خط ذهبي رفيع `#C3A26B` بعرض 120px تحت الشعار.
- **«احجزي استشارتك لتقييم بشرتك»** 56px موف، y≈860.
- **[وسيلة التواصل المعتمدة]** 40px سيج داكن، y≈980.
- التنويه الطبي 26px رمادي دافئ، y≈1380.
- شارة الذكاء الاصطناعي تبقى ظاهرة.

### الانتقالات والحركة
- قطع مباشر (Hard cut) بين اللقطات المتحدثة، أو Dissolve 6 إطارات كحد أقصى.
- بدون Zoom سريع، أو Glitch، أو مؤثرات صوتية حادة.

### الصوت والموسيقى
- الصوت البشري: −14 LUFS متكامل للمخرج النهائي، الذروة ≤ −1 dBTP.
- الموسيقى: بيانو/أوتار ناعمة بدون كلمات، 70–85 BPM، مرخّصة تجاريًا، أخفض من الصوت بـ 18–22 dB أثناء الكلام، ترتفع قليلًا في البطاقة الختامية.

### التلوين
- حرارة لون موحدة بين اللقطات، تباين منخفض-متوسط، الحفاظ على تفاصيل البشرة. مطابقة لون الموف والعاجي في كل لقطة (فحص Vectorscope).

## 7) قائمة الامتثال قبل النشر

- [ ] اسم المنتج ونطقه وعبوته مطابقة للصورة الأصلية المعتمدة.
- [ ] لا ادعاءات خاصة بالمنتج غير مدعومة بالنشرة المعتمدة.
- [ ] لا عبارات مثل: «نتائج مضمونة» · «آمن تمامًا» · «بلا آثار جانبية» · «يناسب الجميع».
- [ ] لا حقن، أو إبر، أو تعليمات حقن، أو صور قبل/بعد.
- [ ] الشخصية خيالية: بلا اسم أو لقب أو مؤهلات أو شارة.
- [ ] شارة «مشهد تمثيلي مولّد بالذكاء الاصطناعي» مقروءة طوال الفيديو.
- [ ] التنويه الطبي ظاهر ومقروء.
- [ ] مراجعة واعتماد من طبيب مسؤول بالعيادة.
- [ ] موافقة الجهة المنظمة للإعلانات الطبية في بلد النشر (حسب الحاجة).
- [ ] تفعيل وسم المحتوى المولّد بالذكاء الاصطناعي في إنستجرام عند النشر.
- [ ] فحص الإطارات: الأصابع، الأسنان، حواف الحجاب، الحروف.
