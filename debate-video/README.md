# مُناظرة بين جيلين — إعادة إنتاج احترافية

إعادة إنتاج فيديو فعالية **اليوم الدولي للتعليم: «مُناظرة بين جيلين (جيلٌ أبدع وجيلٌ أبهر)»** بأسلوب موشن جرافيك تعليمي مؤسسي، مع الإبقاء على الصوت الأصلي للمناظرة وإضافة تعليق صوتي عربي احترافي.

- المقاس: 1080×1920 رأسي، 30 إطارًا/ث، H.264 + AAC، faststart.
- الأداة: [Remotion](https://www.remotion.dev) (React) للرسوم، وFFmpeg + Python للصوت والتصدير.
- الخطوط: Cairo وTajawal (رخصة SIL OFL 1.1) محمّلة محليًا من `public/fonts`.

## هيكل المشروع

```
input/source.mp4                 الفيديو المرجعي (المصدر الوحيد للمحتوى)
scripts/segments.json            أزمنة القص: مقاطع المناظرة، مقاطع القاعة، مواضع صور التكريم
scripts/extract-assets.py        استخراج المقاطع والصور وتنظيف صوت المناظرة
narration/narration.json         نص التعليق (للعرض + نص المحرك المشكول) ومدده وروابطه
narration/timings.md             جدول توقيتات التعليق ومقاطع الصوت الأصلي (مولَّد)
scripts/fetch-narration.sh       تنزيل ملفات التعليق المولّدة
scripts/build-timeline.mjs       بناء الخط الزمني + ملف الترجمة SRT
scripts/make-music.py            موسيقى خلفية أصلية مولّدة برمجيًا (بلا قيود ترخيص)
scripts/mix-audio.py             المزج والتطبيع الصوتي (-16 LUFS / -1.5 dBTP)
scripts/render.mjs               رندر الفيديو (بلا صوت) أو لقطات ثابتة للمراجعة
scripts/export.sh                النسخة الرئيسية + نسخة المشاركة + نسخة مترجمة (اختيارية)
src/config/content.ts            كل النصوص والأسماء والعبارات — عدّل هنا
src/config/theme.ts              الألوان والخطوط والمقاسات
src/config/timeline.json         الخط الزمني (مولَّد — لا تعدّله يدويًا)
src/components/                  الشخصيات، المنصة، بطاقة العبارة، الموجة الصوتية، الإطارات
src/scenes/                      المشاهد: الافتتاحية، الفعالية، المتحدثات، المحاور، المناظرة، التكريم، الختام
```

## التشغيل

المتطلبات: Node 18+، Python 3 مع numpy، FFmpeg، ومتصفح Chromium (يُحدَّد مساره بـ `REMOTION_BROWSER` إن لزم).

```bash
npm install
python3 scripts/extract-assets.py          # الأصول من الفيديو المرجعي
bash scripts/fetch-narration.sh            # ملفات التعليق الصوتي (انظر الملاحظة أدناه)
node scripts/build-timeline.mjs            # الخط الزمني + الترجمة
npm run studio                             # معاينة وتعديل تفاعلي (اضبط withAudio=true للاستماع)
node scripts/render.mjs                    # رندر الفيديو بلا صوت ← out/video-silent.mp4
python3 scripts/mix-audio.py               # المزج الصوتي ← out/mix-final.wav
SUBS=1 bash scripts/export.sh              # التصدير ← out/final/
```

بعد تعديل نص أو لون: أعد `render.mjs` ثم `export.sh`. بعد تعديل أزمنة القص أو التعليق: ابدأ من `extract-assets.py` / `build-timeline.mjs`.

## التعليق الصوتي

- المحرك: ElevenLabs عبر Higgsfield (`text2speech_v2`)، صوت جاهز «Soraya» (صوت نسائي، دافئ ومنخفض الطبقة)، دون أي استنساخ لصوت شخص حقيقي أو للمشاركات.
- اختير الصوت من بين 6 عينات بعد تفريغها آليًا بـ Whisper large-v3-turbo لقياس سلامة النطق؛ وأُعيد توليد 3 أسطر بتشكيل معدّل حتى طابق التفريغ النص حرفيًا (مثل «الحفظ… والفهم»، «روضة بنت محمد»).
- النص الكامل والتشكيل الانتقائي في `narration/narration.json`، والتوقيتات في `narration/timings.md`.
- لإعادة التوليد بصوت آخر: ولّد الأسطر بنص الحقل `tts`، ضع الملفات بأسماء `n01.mp3…n10.mp3` في `public/assets/audio/narration/`، حدّث المدد في `narration.json`، ثم أعد الخطوات من `build-timeline.mjs`.

## قرارات تحريرية

- المحتوى والأسماء والجهات والعبارات مأخوذة حرفيًا من الفيديو المرجعي. لم تُختلق معلومات.
- مقاطع المناظرة الأصلية (16 مقطعًا، ≈ 4:09 دقائق) محفوظة كاملة دون اختصار داخلي حتى لا يتغير معنى أي مداخلة؛ القص يتم فقط عند حدود المقاطع وفي أهدأ لحظة.
- نسبة كل عبارة إلى «الجيل المبدع» أو «الجيل المبهر» مطابقة لما أظهره الفيديو المرجعي (لم تُنسب أي عبارة لشخص بعينه).
- التاريخ يُعرض «22 يناير 2026» دون اسم اليوم (بطاقة المصدر تقول «الأربعاء»، و22 يناير 2026 يوافق الخميس).
- «إدارة الهوية والتراث» بدل «إدارة الهيئة والتراث» الواردة في المصدر، بتأكيد من صاحب العمل.
- استُبعدت صورة كشوف أسماء الحضور (p11) من معرض التكريم.

## قيود فنية معروفة

- **تفريغ كلام المناظرة:** الصوت الأصلي بلهجة خليجية في قاعة ذات صدى، ولم تتوفر في بيئة العمل أداة تفريغ دقيقة بما يكفي لنقل الكلام حرفيًا. لذلك تعرض الترجمة لكل مقطع أصلي **العبارة المحورية كما وردت في المصدر** بين علامتي تنصيص مع وسم «[صوت أصلي]»، وليس نصًا حرفيًا للكلام. لإضافة تفريغ حرفي: حرّر `out/subtitles.ar.srt` يدويًا أو أضف التفريغ إلى السكربت.
- **المقاطع المصورة الأصلية:** معظم «المقاطع الواقعية» في المرجع مصوّرة باتجاه الأرضية (توثيق صوتي فعليًا)، فلم تُستخدم بصريًا. المستخدم منها: لقطتا شاشة القاعة، و12 صورة تكريم. هذه مقتطعة من نوافذ صغيرة داخل التصميم الأصلي (≈166×127 و350×268 بكسل)، فعرضها بحجم أكبر يبقى ناعم التفاصيل؛ لم يُدَّعَ استعادة تفاصيل غير موجودة.
- **الموسيقى:** مولّدة برمجيًا داخل المشروع (لم يتوفر مصدر موسيقى مرخّصة)، ويمكن استبدالها بملف مرخّص في `public/assets/audio/music/bed.wav` مع إزالة سطر توليدها من `mix-audio.py`.
- **ترخيص Remotion:** مجاني للأفراد والجهات حتى 3 موظفين؛ الجهات الأكبر تحتاج ترخيص شركة (remotion.pro).
