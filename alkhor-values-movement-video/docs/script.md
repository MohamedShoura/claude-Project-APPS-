# فيديو تعليمي: «بالقيم نرتقي.. وبالحركة نتميز»

## 1) تحليل الصورة

**النوع:** إعلان مدرسي (بوستر عمودي 1024×1536) لإطلاق برنامج، بهوية قطرية (العنابي والأبيض والوردي)، مع شخصية كرتونية لطالبة تركض بزي رياضي، ومبنى المدرسة، وأدوات رياضية (كرة، قارورة ماء، سجادة تمارين، أقماع).

**النصوص المستخرجة حرفيًا:**

| الموضع | النص |
|---|---|
| الترويسة | وزارة التربية والتعليم والتعليم العالي — Ministry of Education and Higher Education — State of Qatar / دولة قطر |
| المدرسة | مدرسة الخور الابتدائية للبنات — Al Khor Primary School for Girls |
| الشارة | إطلاق برنامج |
| العنوان | بالقيم نرتقي.. وبالحركة نتميز |
| الشراكة | بالشراكة مع أولياء الأمور |
| الوصف | برنامج مدرسي مجتمعي متكامل يعزز نمط الحياة الصحية لدى طالباتنا من خلال الحركة المنتظمة والقيم الإيجابية داخل المدرسة وخارجها. |
| الموعد | يبدأ البرنامج في شهر **توفمير** ⟵ انظر الملاحظة |
| المحور 1 | عادات صحية مستدامة (الحركة، التغذية، النوم، والماء) |
| المحور 2 | شراكة مجتمعية مع أولياء الأمور عبر مبادرات منزلية بسيطة وقابلة للتطبيق. |
| المحور 3 | تعزيز القيم والمهارات الحياتية (التعاون، الانضباط، المثابرة، روح القيادة) |
| المحور 4 | مجتمع مدرسي نشط وصحي |
| التذييل | قسم التربية البدنية |

> **ملاحظة على الموعد:** الكلمة في الإعلان «توفمير»، وهي خطأ مطبعي واضح لـ«نوفمبر» (لا يوجد شهر بهذا الاسم). اعتمد الفيديو «نوفمبر». إن كان المقصود غير ذلك فعدّل `facts.startMonth` في `config/config.json` ونص التعليق، ثم أعد الرندر.

**العلاقات بين الأجزاء:** العنوان (الشعار) ← يشرحه الوصف (الهدف والأداتان) ← تفصّله المحاور الأربعة ← وتدعمه الشراكة مع الأسرة ← ويحدد الموعد بداية التنفيذ.

## 2) الأهداف التعليمية

**الهدف الرئيسي:** أن يفهم المشاهد فكرة برنامج «بالقيم نرتقي.. وبالحركة نتميز» وهدفه ومحاوره.

**نتائج التعلم المتوقعة — بعد المشاهدة يستطيع المشاهد أن:**
1. يشرح معنى شطري الشعار (القيم ↔ الارتقاء، الحركة ↔ التميز).
2. يعدّد المحاور الأربعة للبرنامج، ويذكر العادات الصحية الأربع (الحركة، التغذية، النوم، الماء).
3. يذكر دور الأسرة في البرنامج وموعد بدئه.

**الجمهور:** عام مبتدئ (طالبات وأولياء أمور)، بعربية فصحى مبسطة.

**ما أُضيف على الصورة (مُميَّز داخل الفيديو):**
- سطرا «المعنى» في مشهد الشعار: شرح مبسّط لا نص حرفي.
- المثال التطبيقي (يوم طالبة) معنون على الشاشة بـ«مثال مقترح للتوضيح – ليس من نص الإعلان».
- السؤال التفاعلي مبني بالكامل على نص الإعلان.
