# حركة وأكل متوازن — ريل ٢٠ ثانية (1080×1920)

فيديو موشن جرافيك عربي رأسي لريلز وتيك توك يجمع بين حركات بسيطة ونموذج يوم غذائي متوازن.

| البند | القيمة |
|---|---|
| المدة | 20.000 ثانية (600 إطار @ 30fps) |
| المقاس | 1080×1920، H.264 yuv420p، صوت AAC 48kHz |
| الصوت | تعليق مصري (ElevenLabs v4 عبر Higgsfield) + موسيقى أصلية مولّدة برمجيًا، −14 LUFS |
| الصور | صور واقعية مولّدة بـ Higgsfield (gpt_image_2_5) بإضاءة طبيعية |

## الملفات

- `index.html` — المشهد كاملًا. يعمل كمشغّل (تشغيل / إيقاف / إعادة / شريط تقديم) وكمصدر للتصدير.
  كل إطار يُحسب من دالة واحدة `render(t)`، لذلك المعاينة والتصدير متطابقان إطارًا بإطار.
- `tools/make_music.py` — يولّد موسيقى رياضية خفيفة 120 BPM (سينث برمجي من الصفر، دون عينات، ودون حقوق لطرف ثالث).
- `tools/mix.sh` — يقطّع التعليق الصوتي عند وقفاته الطبيعية، ويضع كل جملة على مشهدها، ويخفض الموسيقى تحت الصوت، ويقصّ الناتج على 20.000 ثانية.
- `tools/render.mjs` — يصدّر 600 إطار عبر Chromium (Playwright) إلى ffmpeg.

### نص التعليق الصوتي المستخدم (لهجة مصرية)
«يومك الصحي بيبدأ بخطوة! امشي… واتحرّك على قدّ قدرتك. فطار: شوفان وزبادي وفاكهة. غدا: فراخ ورز وسلطة. وعشا: حمص وعيش حبوب كاملة وخضار. اشرب ميّه، وجهّز أكلك. ابدأ بخطوة… وكرّرها بكرة!»

غيّرنا «دجاج» إلى «فراخ» و«مياه» إلى «ميّه» في الصوت فقط لتكون اللهجة مصرية طبيعية. النص المكتوب على الشاشة بقي كما في السيناريو.

## مساحات الأمان والكتابة
- كل النصوص داخل المنطقة x: 100–930 وy: 210–1450؛ أي بعيدًا عن أزرار المنصة على اليمين وعن الوصف والاسم أسفل الشاشة.
- الخط Cairo (800/900)، وحجم العناوين 88–96px، وأصغر نص 34–36px.
- `dir="rtl"` على الصفحة، والنص يُرسم بمحرك المتصفح فلا يظهر مقلوبًا أو مفكك الحروف.

## الضوابط
- لا وعود بخسارة وزن ولا نتائج مضمونة ولا صور قبل/بعد.
- الوجبات معروضة كـ«نموذج»، مع ملاحظة «الكميات حسب احتياجك».
- الحركات هادئة وآمنة: مشي، وجلوس وقيام بجانب كرسي، وتمدد جانبي خفيف.

## طريقة التصدير
```bash
# المتطلبات: node + playwright (Chromium)، ffmpeg، python3 + numpy
# 1) ضع الصور في مجلد a/ بالأسماء الموجودة في ASSETS داخل index.html، وضع التعليق في a/vo_raw.mp3
python3 tools/make_music.py music.wav
./tools/mix.sh a/vo_raw.mp3 music.wav mix.m4a
node tools/render.mjs "file://$PWD/index.html?render=1&assets=a/" video.mp4
ffmpeg -i video.mp4 -i mix.m4a -c:v copy -c:a copy -t 20 -movflags +faststart final.mp4
```
للمعاينة: افتح `index.html` في المتصفح. تُحمَّل الصور والصوت النهائي من روابط Higgsfield، ويمكن تغيير الصوت بـ `?audio=<رابط>`.
